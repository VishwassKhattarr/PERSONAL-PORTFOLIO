Edge AI Bird Species Classification

Built a real-time edge AI system for bird species recognition using audio classification. Designed a four-stage inference pipeline with frequency-domain filtering, lightweight CNN-based detection, feature-extraction using librosa and multi- label classification. Achieved F1 score of 0.79 across 150+ species; reduced unnecessary inference by ∼60% via audio energy gating. Benchmarked TFLite quantization formats (float32, float16, int8) for on-device deployment
